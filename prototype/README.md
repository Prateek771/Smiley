# Saavantus claims desk concept

Open `../outputs/Saavantus-claims-desk-prototype.html` in a browser. It is a standalone interactive HTML prototype with no installation or server required. Source files live in this folder; run `node build.js` after editing them to rebuild the standalone file.

The five fictional cases illustrate document preparation, an insurer query, a payer decision awaiting Billing, partial remittance, and eligibility before pre-authorisation. Use the role selector in the header to preview Desk, Billing, Finance, and Admin handoffs. Start the guided walkthrough on Overview, or open any case from the work queue. Changes are saved only in this browser and can be cleared with **Settings → Reset demo**.

All patients, payers, authorisations, acknowledgements, AI responses, and payments are sample data. The controls do not contact a hospital system, AI model, insurer, TPA, or payment service. Do not enter real patient information into the demo.
